# App icon

The iPhone/iPad icon is the opaque 1024 × 1024 PNG at
[`AppIcon.png`](../Resources/Assets.xcassets/AppIcon.appiconset/AppIcon.png).
It was generated with the built-in image generation tool on 2026-10-07,
then resized for the existing Xcode AppIcon asset set. iOS applies the corner mask.

Generation prompt:

> Use case: logo-brand. Create one polished iPhone/iPad app icon for SquirrelPad: a single charming cartoon acorn, large and centered, with a warm golden-brown body, chunky textured brown cap and short curved stem. Playful, sculpted cartoon illustration with a strong clean silhouette, gentle highlights and dimensional shading. Simple softly lit background that complements the warm acorn. Recognizable at tiny home-screen size. Full-bleed square 1024x1024 artwork, opaque background, no rounded-corner mask, no border, no letters, no words, no watermark, no other objects.

The older `scripts/generate-app-icon.swift` draws the previous geometric mark;
it does not reproduce this artwork and should not be run to regenerate it.
